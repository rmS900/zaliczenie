### Opis projektu

Celem projektu jest stworzenie prostej strony internetowej prezentującej zwierzęta oraz podstawowe informacje na ich temat. Projekt jest realizowany zespołowo jako ćwiczenie pracy grupowej na platformie GitHub.

### Jak uruchomić

Nie musisz instalować dodatkowego oprogramowania. Wystarczy przeglądarka internetowa. Stronę można uruchomić poprzez otwarcie pliku `index.html`.
